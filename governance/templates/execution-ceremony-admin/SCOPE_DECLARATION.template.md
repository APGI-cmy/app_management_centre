> **Usage**: This template defines the canonical structure for `.agent-admin/scope-declarations/pr-<PR_NUMBER>.md`. Generate this file using `git diff --name-only origin/main...HEAD` as the source. This must be the **last committed file** before IAA invocation (per ECAP-QC-002 / §4.3d). The deprecated shared file `governance/scope-declaration.md` must **not** be used as per-PR scope evidence.

## Generation Script

```bash
#!/bin/bash
# Generate per-PR scope declaration — ECAP-QC-002 / §4.3d
# Must be run as the absolute last step before IAA invocation.
# Requires PR_NUMBER to be set (export PR_NUMBER=<number> before running).

if [ -z "${PR_NUMBER:-}" ]; then
  echo "❌ PR_NUMBER is not set. Export it before running this script."
  exit 1
fi

BRANCH=$(git branch --show-current)
FILES=$(git diff --name-only origin/main...HEAD)
COUNT=$(echo "${FILES}" | wc -l | tr -d ' ')
OUT_DIR=".agent-admin/scope-declarations"
OUT_FILE="${OUT_DIR}/pr-${PR_NUMBER}.md"
mkdir -p "${OUT_DIR}"

cat > "${OUT_FILE}" <<EOF
# Scope Declaration — PR #${PR_NUMBER}

<!-- Version: v2.0.0 | per-PR immutable scope declaration; authority: CS2 — issue #1359 -->
SCOPE_SCHEMA_VERSION: v2
PR_NUMBER: ${PR_NUMBER}
ISSUE: #ISSUE_NUMBER_HERE — ISSUE_TITLE_HERE
BRANCH: ${BRANCH}
OWNER: execution-ceremony-admin-agent
DATE_UTC: $(date -u +"%Y-%m-%dT%H:%M:%SZ")

## PR Responsibility Domain
RESPONSIBILITY_DOMAIN: <single noun phrase>

## Explicitly In Scope
IN_SCOPE:
$(echo "${FILES}" | sed 's/^/- /')

## Explicitly Out of Scope
OUT_OF_SCOPE:
- Tests
- CI
- Migrations

## Expected Verification Signal
EXPECTED_VERIFICATION:
- CI: GREEN
- TESTS: UNCHANGED | GREEN
- GOVERNANCE_GATES: GREEN

## Scope Freeze Declaration
SCOPE_FROZEN: YES

## FILES_CHANGED

FILES_CHANGED: ${COUNT}

$(echo "${FILES}" | sed 's/^/- /')

---

*Per-PR immutable scope declaration. File: \`${OUT_FILE}\`.
Introduced by PR #${PR_NUMBER}. Not to be modified by subsequent PRs.*
EOF

echo "✅ Scope declaration generated: ${OUT_FILE} (FILES_CHANGED=${COUNT})"
echo "   Commit this file, then proceed to §4.3d parity verification."
```
